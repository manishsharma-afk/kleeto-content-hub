# kleeto content hub

Login-protected dashboard, content calendar and post review for kleeto.

- Live site: https://manishsharma-afk.github.io/kleeto-content-hub/
- Sign-in: email link (Supabase Auth). Only allow-listed emails can see data.
- Data, images and videos live in Supabase (private), not in this repo. This repo only holds the page.
- Comments left on a post go to Rio, who makes the change and replies in the thread.
